## Title

Koi — Human-agent collaborative design with native WebMCP

## Description

Koi is an open-source, local-first spatial design workspace where people and browser agents edit
the same semantic design document.

This demonstration uses a deterministic release harness and Koi's real native WebMCP surface to
discover trusted Astryx components, inspect stable Element IDs and versions, create a visible
design alternative, preserve it across a reload, exercise the human interaction path, and safely
refine the result. The harness makes real `document.modelContext` calls and sends real pointer and
keyboard events; it is release evidence rather than a recording of live human input, model
deliberation, or ChatGPT's Site Tools chrome. Human gestures and agent tool calls enter the same
validated command/query core, so stale agent writes are rejected instead of silently replacing
newer human work.
